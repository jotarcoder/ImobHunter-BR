# Distribuição

O produto possui quatro destinos planejados:

- Windows: instalador .exe;
- Linux: AppImage;
- macOS Intel: .dmg;
- macOS Apple Silicon: .dmg.

Os nomes são mantidos estáveis para que a central web e a extensão apontem para a mesma release.

A geração final de artefatos ocorre em pipeline de release depois que CI estiver verde. O repositório não versiona binários grandes.
